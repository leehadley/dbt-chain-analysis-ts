# DBT 7-Step Psychological Chain Analysis App

An interactive, visual Single-Page Application (SPA) designed to help individuals and clinicians create, analyze, and visualize **DBT Behavioral Chain Analyses**. 

Tailored with specialized vulnerability options and coping circuit breakers for **CPTSD (Complex Trauma)**, **ASD (Autism Spectrum)**, and **ADHD (Executive Functioning / RSD)**.

## ✨ Features

- **🧙 Guided 7-Step Wizard Mode**:
  1. *Target Behavior*: Severity (1–10), category, context.
  2. *Vulnerabilities*: Pre-conditions with **one-click presets for ADHD, ASD, CPTSD, & Sleep/Health**.
  3. *Prompting Event*: Pinpoint the trigger & timing.
  4. *Chain of Links*: Sequence builder for Thoughts (🧠), Emotions (❤️), Sensations (🫀), and Impulses (🚶) with intensity levels.
  5. *Consequences*: Short-term relief vs. long-term impact.
  6. *Coping Skill Interventions*: Attach DBT coping skills directly to links as circuit breakers.
  7. *Prevention & Repair Plan*: Future vulnerability reduction & amends.

- **🎨 Interactive Visual Flowchart Canvas**:
  - Horizontal & Vertical flowchart sequence diagram.
  - **Emotional Arousal Curve Graph** (mapping intensity from 1 to 10 across the chain).
  - Quick-attach coping skill shields.

- **📚 DBT Coping Skills Library**:
  - Catalog of skills: **STOP**, **TIPP**, **Check the Facts**, **Radical Acceptance**, **Opposite Action**, **Wise Mind**, **DEAR MAN**, **Self-Soothe (5 Senses)**, **Wave Skill (Urge Surfing)**, **PLEASE Skills**, **Post-Mortem Gatekeeper (Audit Block)**, **De-linking Ambiguity**, and **Sensory & Routine Shield**.

- **📁 Local Privacy & Storage Manager**:
  - 100% Client-side local storage (`localStorage`).
  - Pre-loaded templates (Workplace Outburst & **Full ASD/ADHD/CPTSD Social Avoidance Chain Analysis**).
  - Export & Import JSON analyses.

- **📄 Printable Clinical Report**:
  - Clean formatted summary for therapy sessions or personal archiving.

## 🚀 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/dbt-chain-analysis.git

# Navigate into directory
cd dbt-chain-analysis

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🌐 Deploy Free Live Demo

### Option 1: Netlify Drop (30 Seconds, No Build Tools)
1. Run `npm run build` locally.
2. Drag and drop the `dist/` folder into [app.netlify.app/drop](https://app.netlify.app/drop).

### Option 2: Vercel / GitHub Pages
1. Push this repository to GitHub.
2. Import the repo at [Vercel.com](https://vercel.com) for auto-deployment with free HTTPS.
